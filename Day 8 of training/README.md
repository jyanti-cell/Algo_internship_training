# 🏥 Hospital Patient Registry System

A sleek, modern micro-service engine built to manage patient onboarding channels. Engineered specifically around **Algotutor Module 2 (Day 8: Express.js, Routing & Middleware)** principles, this workspace covers fast client-server handshake flows, native body extraction hooks, and immediate server-side data persistence.

## ⚡ Production Pipeline Checklist (Day 8 Implementation)

### 🔌 1. Framework Mounting & Server Lifecycle
* Instantiated high-performance request tracking via **Express.js**.
* Standardized network communication bridges by running on **PORT 5000**.

### 🛡️ 2. Native System Middleware
* **Payload Unpackers:** Integrated `express.urlencoded({extended: true})` globally to safely parse form data formats.
* **Asset Servicing:** Mounted static assets via `express.static()` to auto-load frontend style sheets dynamically.

### 🌐 3. Data Flow Operations & Route Lifecycle
* `GET /` ── Resolves paths to spin up the semantic HTML registration form layout.
* `POST /register` ── Synchronously streams, handles data strings, appends records via `fs.appendFileSync()`, and renders an elegant, inline Success Modal.
* `GET /students` ── Evaluates file tracks using `fs.existsSync()`, fetches buffered strings synchronously using `fs.readFileSync()`, and outputs a stylized console table summary view.

2. Initialize environment components inside your terminal:

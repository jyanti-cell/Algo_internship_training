# Day 3: JavaScript Fundamentals & DOM Manipulation

Today, I advanced my college "Tech Fest 2026" website by integrating dynamic behavioral logic using JavaScript. I focused on making the user experience interactive, specifically targeting form handling and dynamic page updates.

## 🛠️ Topics Covered & Implemented:
* **Variables (let/const):** Storing and managing user-input form values safely.
* **Functions:** Creating operational logic like `processform()` to handle button actions.
* **Form Validation:** Checking if inputs are empty before submitting data.
* **Loops (for loop):** Iterating through radio button elements to extract the user's selected gender.
* **Dynamic DOM Manipulation:** Generating new HTML elements (`document.createElement`) and updating the UI instantly using `.innerHTML`.

## 💻 Tech Fest 2026 Project Improvements:
* **Form Authentication:** The registration system now blocks incomplete entries and sends live alerts.
* **Dynamic Registration Card:** Upon a successful signup, a clean, styled success confirmation card appears instantly below the form showcasing user choices without reloading the page.
* **Form Reset State:** Utilized form resets to instantly clear inputs once a user registers successfully.

## 📂 Project Files Added:
* `index.html` - Enhanced registration layout containing structural hooks and event handling (`onclick`).
* `style.css` - Custom styling stylesheet creating responsive forms and beautiful alert popups.
* `domscript.js` - Dedicated JavaScript logic controller driving the DOM manipulation systems.

# Day 2 of training: CSS Basics, Flexbox, Grid, Responsive Design

Today I worked on the fundamental styling concepts of web development and applied them to build a responsive portfolio page.

## Topics Covered:
* **CSS Basics:** Selectors, box model, colors, and typography.
* **Flexbox:** Aligning items, centering elements, and managing flexible layouts.
* **CSS Grid:** Creating structured, multi-column grid structures easily.
* **Responsive Design:** Using media queries to ensure the page looks good on mobile, tablet, and desktop screens.

## Project Files Added:
* `myportfolio.html` - The main structure of the portfolio updated with semantic HTML and styling classes.
* `style.css` - Custom styling stylesheet utilizing CSS Grid and Flexbox for a responsive layout.
